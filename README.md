Việt Hóa game Titanfall 2 bằng cách chèn VPK

# Hướng dẫn tải
Trước bắt đầu thì backup 2 file "client_frontend.bsp.pak000_000.vpk" và "englishclient_frontend.bsp.pak000_dir.vpk" trong mục "Titanfall2/vpk" nếu như có vấn để hoặc bạn muốn về tiếng Anh.

Sau đó giải nén file zip đã tải về và thay thế 2 file đó. Tiếng Anh sẽ được thay thế bằng tiếng Việt và bạn có thể bắt đầu chơi.
